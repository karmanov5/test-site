# Сервисы Интернета — 11 класс

Интерактивный урок: 17 учебных экранов и тест из 10 вопросов. Сайт работает без сборки и внешних библиотек.

## Источники

Материал и иллюстрация взяты только из предоставленных презентаций:

- **А** — `Презентация_Сервисы_Интернета_11_класс.pptx`, 16 слайдов, включая текст диаграмм SmartArt.
- **Б** — `Презентация Виды деятельности в сети Интернет. Сер.pptx`, 8 слайдов.

Под каждым экраном и в разборе вопросов указаны номера слайдов источника. Тексты адаптированы для чтения на сайте. Вопросы и неверные варианты ответов составлены для самопроверки по материалу презентаций. Таймер и шкала оценки — настройки сайта, а не утверждения из источников.

## Использование

Переключение: кнопки, разделы, стрелки клавиатуры и горизонтальный свайп. Перед тестом обязательны имя и фамилия. Один вопрос занимает не более 30 секунд. Истечение времени автоматически даёт 0 баллов и открывает следующий вопрос. Обновление страницы и уход в другую вкладку не сбрасывают срок ответа.

За верный ответ начисляется 1 балл. Оценки: 9–10 → 5, 7–8 → 4, 5–6 → 3, 0–4 → 2. Попытка и последний результат сохраняются в localStorage с префиксом `internet-services-11-v1`. Если браузер запрещает запись, сайт сообщает об этом. Хранилище привязано к браузеру и устройству. Это самопроверка, не защищённая экзаменационная система.

Кнопка «Поделиться результатом с учителем» рисует PNG-карточку через Canvas, инициирует скачивание и открывает указанную ссылку MAX. Файл ученик прикрепляет самостоятельно. Если браузер заблокировал новую вкладку или загрузку, доступны отдельные ссылки. Canvas выбран вместо html2canvas, чтобы не загружать внешние библиотеки. Имя и результат не отправляются на сервер сайта.

## Публикация

Каталог `internet-services` размещается в существующей ветке `main` репозитория `karmanov5/test-site`, у которого уже настроен GitHub Pages. Корень существующего сайта сохраняется.

Адрес раздела: https://karmanov5.github.io/test-site/internet-services/

Для локальной проверки отдайте этот каталог любым статическим HTTP-сервером. `index.html`, `style.css`, `content.js`, `app.js` и `assets/lesson.png` должны оставаться рядом в указанной структуре.
